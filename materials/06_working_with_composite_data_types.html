10  Working with Composite Data Types

TipLearning Objectives
  • Understand mutability and immutability across Python composite data types.
  • Access individual elements and slices using positional indexing ([0], [1:3]) and key lookups (["key"]).
  • Use key built-in list methods (e.g. .append(), .extend(), .pop(), .sort()).
  • Use key built-in dictionary methods (e.g. .get(), .keys(), .values(), .items()).
  • Store unique and fixed collections using sets and tuples.
  • Solve multi-step problems using composite data structures.

10.1 Overview of Composite Data Types

In Python, composite data types allow you to group multiple values into a single variable. The four main composite data types behave differently regarding mutability, order, and duplicates:

Data Type Mutable? Ordered? Allows Duplicates? Common Use Case
List Yes Yes Yes Storing sequential items that change over time
Tuple No Yes Yes Storing fixed groups of values (e.g. coordinates)
Dictionary Yes Yes (insertion order) Keys: No, Values: Yes Looking up values using unique labels
Set Yes No No Tracking unique items and removing duplicates

10.1.1 Demonstrating Mutability vs Immutability

Mutable objects can have their content altered in place after creation. Immutable objects cannot be changed directly and will raise an error if you attempt to modify their elements.

# Lists are mutable: elements can be modified in place
shopping_list = ["bread", "milk", "butter"]
shopping_list[0] = "sourdough"
print("Modified List:", shopping_list)

# Dictionaries are mutable: values can be updated or added
catalogue = {"laptop": 850, "mouse": 25}
catalogue["mouse"] = 20
catalogue["keyboard"] = 45
print("Modified Dictionary:", catalogue)
Modified List: ['sourdough', 'milk', 'butter']
Modified Dictionary: {'laptop': 850, 'mouse': 20, 'keyboard': 45}
# Tuples are immutable: attempting to change an item raises an error
coordinates = (51.5074, -0.1278)
coordinates[0] = 52.0

output:

TypeError                                 Traceback (most recent call last)
/tmp/ipykernel_1691/4027946773.py in <cell line: 0>()
      1 coordinates = (51.5074, -0.1278)
----> 2 coordinates[0] = 52.0

TypeError: 'tuple' object does not support item assignment

10.2 Working with Lists

Lists are ordered, indexable sequences. You can access individual items using zero-based indexing or retrieve multiple items using slicing.

10.2.1 Accessing List Elements & Slicing

  • Index 0: Retrieves the first element.
  • Index -1: Retrieves the last element.
  • Slice [start:stop_before]: Extracts a sub-list.
cities = ["London", "Manchester", "Edinburgh", "Cardiff", "Belfast"]

# Accessing individual elements by index
first_city = cities[0]
second_city = cities[1]
last_city = cities[-1]

print("First city [0]:", first_city)
print("Second city [1]:", second_city)
print("Last city [-1]:", last_city)

# Slicing a list [start:stop_before]
middle_cities = cities[1:4]  # Extracts indices 1, 2, and 3
first_two = cities[:2]       # Extracts up to (but excluding) index 2

print("Slice [1:4]:", middle_cities)
print("Slice [:2]:", first_two)
First city [0]: London
Second city [1]: Manchester
Last city [-1]: Belfast
Slice [1:4]: ['Manchester', 'Edinburgh', 'Cardiff']
Slice [:2]: ['London', 'Manchester']

10.2.2 Useful Built-in List Methods

Method / Function Purpose Example Syntax
list.append(x) Adds item x to the end of the list items.append("tea")
list.extend(iterable) Appends all items from a collection to the end items.extend(["milk", "sugar"])
list.insert(i, x) Inserts item x at index i items.insert(0, "coffee")
list.remove(x) Removes the first occurrence of value x items.remove("tea")
list.pop(i) Removes and returns item at index i (default: last item) last_item = items.pop()
list.sort() Sorts items in ascending order in place items.sort()
list.reverse() Reverses the order of items in place items.reverse()
len(list) Returns the total number of items total = len(items)

10.2.3 Demonstrating List Operations

# Initialise a list
animals = ["Lion", "Tiger", "Bear"]

# Adding items
animals.append("Elephant")
animals.extend(["Giraffe", "Zebra"])
print("After append & extend:", animals)

# Inserting at index 1
animals.insert(1, "Monkey")
print("After inserting at index 1:", animals)
print("New element at index 1:", animals[1])

# Removing and popping items
animals.remove("Tiger")
removed_item = animals.pop()  # Removes last item ("Zebra")

print("Removed via pop():", removed_item)
print("After removal & pop:", animals)

# Sorting alphabetically
animals.sort()
print("Alphabetically sorted:", animals)

After inserting at index 1: ['Lion', 'Monkey', 'Tiger', 'Bear', 'Elephant', 'Giraffe', 'Zebra']
New element at index 1: Monkey
Removed via pop(): Zebra
After removal & pop: ['Lion', 'Monkey', 'Bear', 'Elephant', 'Giraffe']
Alphabetically sorted: ['Bear', 'Elephant', 'Giraffe', 'Lion', 'Monkey']

10.3 Working with Dictionaries

Dictionaries map unique keys to values. Rather than using numeric positional indices, you access values using their associated keys.

10.3.1 Accessing Dictionary Elements

book_stock = {
    "Python Programming": 12,
    "Data Analytics": 5,
    "Web Development": 8
}

# Accessing values using key indexing
python_copies = book_stock["Python Programming"]
print("Copies of Python Programming:", python_copies)

# Safely accessing values using .get() (prevents KeyError if key is missing)
cyber_copies = book_stock.get("Cybersecurity", 0)
print("Copies of Cybersecurity (defaulted):", cyber_copies)
Copies of Python Programming: 12
Copies of Cybersecurity (defaulted): 0

10.3.2 Useful Dictionary Methods

Method / Operation Description Example Syntax
dict[key] = value Adds or updates a key-value pair stock["pens"] = 50
dict.get(key, default) Safely retrieves value for key without raising an error stock.get("paper", 0)
dict.keys() Returns a view of all dictionary keys stock.keys()
dict.values() Returns a view of all dictionary values stock.values()
dict.items() Returns key-value pairs as tuples stock.items()
del dict[key] Deletes a key-value pair del stock["pens"]

10.3.3 Demonstrating Dictionary Operations

# Updating and adding items
book_stock["Cybersecurity"] = 4
book_stock["Data Analytics"] = 10  # Updates existing value

print("Updated book stock:", book_stock)
print("All keys:", list(book_stock.keys()))
print("All values:", list(book_stock.values()))

# Iterating through key-value pairs using .items()
print("\nCurrent Inventory:")
for title, quantity in book_stock.items():
    print(f"- {title}: {quantity} copies")
Updated book stock: {'Python Programming': 12, 'Data Analytics': 10, 'Web Development': 8, 'Cybersecurity': 4}
All keys: ['Python Programming', 'Data Analytics', 'Web Development', 'Cybersecurity']
All values: [12, 10, 8, 4]

Current Inventory:
- Python Programming: 12 copies
- Data Analytics: 10 copies
- Web Development: 8 copies
- Cybersecurity: 4 copies

10.4 Working with Tuples and Sets

10.4.1 Tuples

Tuples are ordered and immutable. You access items using positional indexing tuple[index] just like lists, but you cannot modify them.

# Storing fixed geographical coordinates (Latitude, Longitude)
location = (53.4808, -2.2426)

# Accessing elements by index
latitude = location[0]
longitude = location[1]

print("Latitude [0]:", latitude)
print("Longitude [1]:", longitude)
Latitude [0]: 53.4808
Longitude [1]: -2.2426

10.4.2 Sets

Sets store an unordered collection of unique items. Because sets are unordered, they do not support indexing (set[0] will raise an error). Instead, you add items, check membership with in, or convert them to lists.

# Initialising a set with duplicate entries
customer_ids = {101, 102, 103, 101, 104, 102}
print("Unique Customer IDs:", customer_ids)

# Adding items
customer_ids.add(105)
customer_ids.add(103)  # Duplicate, automatically ignored

print("Updated Customer IDs:", customer_ids)

# Checking membership
print("Is 102 in customer_ids?", 102 in customer_ids)
Unique Customer IDs: {104, 101, 102, 103}
Updated Customer IDs: {101, 102, 103, 104, 105}
Is 102 in customer_ids? True
#The below will throw an error
customer_ids = {101, 102, 103, 101, 104, 102}
print(customer_ids[0])

output

----> 2 print(customer_ids[0])

10.6 Summary

TipKey Points
  • Lists and Tuples are ordered sequences accessed via numeric indices ([0], [1], [-1]) and slices ([1:3]).
  • Dictionaries store key-value pairs accessed via keys (dict["key"]) or .get("key").
  • Sets store unordered, unique elements and do not support positional indexing.
  • Lists and Dictionaries are mutable; Tuples are immutable.
  • Built-in methods like .append(), .extend(), .pop(), and .sort() provide powerful ways to manipulate composite collections.
