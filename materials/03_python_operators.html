8  Python Operators

TipLearning Objectives
  • Understand what an operator is, and why we use them
  • Recognise Python’s main groups of operators: arithmetic, comparison, logical, and assignment
  • Know that Python checks operators in a set order (precedence), and how brackets can make this clearer

8.1 What Are Operators?

An operator is a symbol or short keyword that tells Python to do something with a piece of data, such as adding two numbers together, or checking whether one value is bigger than another. Think of the mathematical symbols you already know from school, like + or < — Python uses many of the same ones.

Most operators in Python behave exactly how you would expect. You do not need to memorise every single one right now — there is a complete reference table at the end of this page for whenever you need to look one up. For now, we will focus on the four groups you will use the most: arithmetic, comparison, logical, and assignment operators.

8.2 Arithmetic Operators

Arithmetic operators do the maths you are already familiar with — adding, subtracting, multiplying, and dividing.

a = 7
b = 2

print(a + b)   # addition
print(a - b)   # subtraction
print(a * b)   # multiplication
print(a / b)   # division
9
5
14
3.5

Two of these are less familiar, and are worth a closer look:

  • % (modulus) gives you the remainder left over after dividing.
  • // (floor division) gives you the whole number result of a division, rounding down.
print(a % b)   # remainder after dividing 7 by 2
print(a // b)  # 7 divided by 2, rounded down
1
3

The + operator is not just for numbers — it also works on strings (joining them together) and on lists (combining them). We will see more of this in later sections.

8.3 Comparison Operators

Comparison operators compare two values, and always give you back a boolean — True or False.

x = 10
y = 3

print(x == y)  # equal to
print(x != y)  # not equal to
print(x > y)   # greater than
print(x < y)   # less than
False
True
True
False

8.4 Logical Operators

Logical operators combine booleans together, and are especially useful once you start writing code that makes decisions.

is_raining = True
have_umbrella = False

print(is_raining and have_umbrella)  # both must be true
print(is_raining or have_umbrella)   # either can be true
print(not is_raining)                # flips True to False, and vice versa
False
True
False

8.5 Assignment Operators

You already know the plain = operator for assigning a value to a variable. Python also has shorthand versions that update a variable using its own current value:

score = 5
score += 3  # the same as: score = score + 3
print(score)
8

8.6 A Few Other Operators

Python has several more specialised groups of operators — including bitwise operators, membership operators (in / not in), identity operators (is / is not), and operators just for sets. You will meet these properly in later sections once we have covered lists, strings, and sets in more detail, but as a quick taste, the membership operator in lets you check whether something exists inside a collection:

fruits = ["apple", "banana", "cherry"]
print("banana" in fruits)
True

The full reference tables at the end of this page list all of these, in case you come across one sooner and want to look it up.

8.7 Order of Precedence

When an expression contains more than one operator, Python has to decide which one to work out first. It does this using a fixed order, in much the same way you were taught BODMAS or BIDMAS in school maths.

result = 2 + 3 * 4
print(result)
14

Here, Python works out 3 * 4 first, and only then adds 2, giving 14 rather than 20. If you want to force a different order, you can use brackets — just as you would in maths:

result = (2 + 3) * 4
print(result)
20

Wrapping 2 + 3 in brackets tells Python to work that part out first, giving 20 instead. When in doubt, adding brackets is always a safe way to make your intentions clear, both to Python and to anyone else reading your code.

Operators are checked in a fixed order in code (think BODMAS). Using brackets can add clarity to your code, and removes any doubt about which order Python will use.

4 *, /, //, % Multiplication, division, floor division, modulus a * b, a / b
5 +, - Addition, subtraction a + b, a - b
6 <<, >> Bitwise left shift, right shift a << b, a >> b
7 & Bitwise AND a & b
8 ^ Bitwise XOR a ^ b
9 \| Bitwise OR a \| b
10 in, not in Membership operators 'a' in 'apple'

8.10 Summary

Use the tables above to look up any operator you come across in Python. Operators can make code more concise and readable, and are usually intuitive even to those new to Python. On the other hand, operators can sometimes make code harder to read than using a named function instead, and cannot generally be passed as arguments into higher-order functions. We will look at functions in more detail in the next section.

Operators also behave differently depending on the data type they are used with — try using the * operator to multiply two integers, and then to multiply a string by an integer, to see what happens. We will use operators much more in the next few sections.

TipKey Points
  • Python has a rich set of operators, grouped by the kind of operation they perform
  • Operators can behave differently when used with different data types and structures
  • Operators are checked in a fixed order of precedence in code, in the same way as in mathematics
